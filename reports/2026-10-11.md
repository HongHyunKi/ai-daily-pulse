### 1. Anthropic, Claude Haiku 5.5 공개 - 소형 모델 가격 대폭 인하와 effort control 도입
**카테고리:** LLM / Developer Tool

**주요 내용:**
- Anthropic이 10월 7일 Claude Haiku 5.5를 출시했다. 10만 토큰 이하 프롬프트 기준 입력 100만 토큰당 0.10달러, 출력 0.50달러로, 이전 Haiku 4.5의 1달러/5달러 대비 10분의 1 수준이다.
- 10만 토큰을 넘는 긴 프롬프트는 입력 0.50달러, 출력 2.50달러로 올라가는 2단계 가격 구조를 처음 적용했다. Anthropic은 낮은 단가 구간이 이전 Haiku 요청의 약 90%를 커버한다고 설명한다.
- Haiku 계열 최초로 reasoning effort를 조절하는 설정(Low, Medium, High, Xhigh, Max)을 제공한다. 간단한 작업에서는 추론량을 낮춰 지연과 비용을 줄이고, 복잡한 로직에서는 추론량을 높일 수 있다.
- 한 가지 주의점은 토크나이저가 바뀌어 동일한 입력에 대해 Haiku 4.5보다 약 30% 더 많은 토큰을 생성한다는 점이다. 이를 감안해도 짧은 프롬프트 워크로드는 Haiku 4.5 대비 약 85~90% 저렴하다는 분석이 있다.

**엔지니어 관점 포인트:**
소형 모델의 가격이 10분의 1 수준으로 내려가면 요약, 분류, 서브에이전트 호출처럼 대량으로 반복 호출하는 파이프라인의 단가 구조가 근본적으로 달라진다. 특히 effort control은 같은 모델 안에서 비용과 품질을 코드로 제어할 수 있게 해주므로, 그동안 모델 자체를 바꿔 처리하던 난이도별 라우팅을 하나의 모델로 단순화할 여지가 생긴다. 다만 토크나이저 변경으로 토큰 수가 늘어나는 점은 실제 청구 비용과 컨텍스트 예산 산정에 영향을 주므로, 마이그레이션 전에 자신의 트래픽으로 토큰 수를 다시 측정해보는 것이 안전하다.

**관련 링크:** [letsdatascience.com](https://letsdatascience.com/news/anthropic-releases-claude-haiku-55-with-lower-prices-and-eff-f698c663), [vktr.com](https://www.vktr.com/ai-platforms/anthropic-cuts-smallmodel-pricing-90-with-claude-haiku-55/)

### 2. Mistral, Large 4 퍼블릭 프리뷰 시작 - 오픈 웨이트 1조 파라미터급 MoE
**카테고리:** LLM / Open Source

**주요 내용:**
- Mistral이 10월 6일 플래그십 모델 Large 4를 퍼블릭 프리뷰로 공개했다. 현재는 Mistral Studio API를 통한 호스팅 프리뷰이며, 오픈 웨이트는 이달 말 공개될 예정이다.
- 희소 Mixture-of-Experts 구조로, 토큰마다 네트워크의 일부 전문가(expert)만 활성화한다. 총 파라미터는 약 1.05조 규모로 보고되며, 활성 파라미터 수치는 출처에 따라 49B~52B로 엇갈린다. 텍스트와 이미지 입력을 받고 텍스트를 출력한다.
- 유럽 데이터센터에서 NVIDIA Grace Blackwell(GB200) GPU 3,800대로 처음부터 학습했다고 밝혔다. 컨텍스트 윈도우는 모델 카드 기준 100만 토큰으로 표기되나, 일부 집계에서는 524,288 토큰으로 다르게 나타난다.
- 프리뷰 가격은 입력 100만 토큰당 0.68달러, 출력 2.09달러 수준으로, 정식 가격의 절반으로 제공되고 있다. 라이선스 조건은 아직 공개되지 않았다.

**엔지니어 관점 포인트:**
오픈 웨이트를 표방하는 1조 파라미터급 MoE가 실제로 공개되면, 자체 인프라에서 돌릴 수 있는 프런티어급 모델의 상단이 한 단계 올라간다. MoE 특성상 총 파라미터는 크지만 토큰당 활성 파라미터가 50B 안팎이므로, 추론 비용은 dense 1조 모델보다 훨씬 현실적이다. 다만 현 시점에서는 호스팅 프리뷰만 열려 있고 라이선스와 정확한 활성 파라미터, 컨텍스트 길이가 출처마다 다르므로, 온프레미스 도입을 검토한다면 이달 말 공개될 실제 가중치와 라이선스 문구를 확인한 뒤 판단하는 것이 맞다.

**관련 링크:** [letsdatascience.com](https://letsdatascience.com/news/mistral-debuts-large-4-open-weight-model-preview-cbf9e0b5), [noze.it](https://www.noze.it/en/insights/mistral-large-4-en/)

### 3. JetBrains, Mellum 2.1 Thinking 공개 - 에이전틱 코딩에 특화된 오픈 웨이트 코드 모델
**카테고리:** Open Source / Developer Tool

**주요 내용:**
- JetBrains가 10월 8일 자사 코드 모델 Mellum2의 업그레이드인 Mellum 2.1 Thinking을 공개했다. 12B 규모 MoE 구조에 토큰당 활성 파라미터 2.5B, 컨텍스트 131K를 유지하면서, 실제 레포지토리 기반 강화학습을 강화해 에이전틱 코딩과 도구 호출 능력을 높였다.
- Apache 2.0 라이선스로 가중치가 Hugging Face에 공개됐다. 별도의 호스팅 API 모델이 아니라 직접 받아서 서빙하는 형태다.
- 벤더 자체 벤치마크 기준 SWE-bench Verified에서 47.0(동일 Pi 하니스 기준 Mellum2 Thinking의 2.0 대비), LiveCodeBench v6에서 82.0을 기록했다고 밝혔다. 모두 독립 검증은 아직 없다.
- 서빙은 vLLM(reasoning-parser qwen3, 선택적으로 Hermes 도구 호출)을 권장하며, GGUF와 MTP head는 추후 제공 예정이다.

**엔지니어 관점 포인트:**
12B 규모에 활성 파라미터가 2.5B에 불과한 모델이 에이전틱 코딩 벤치마크에서 의미 있는 점수를 낸다면, IDE 플러그인이나 사내 코딩 에이전트를 로컬·온프레미스로 돌리려는 팀에게 현실적인 선택지가 된다. Apache 2.0 라이선스와 vLLM 지원 덕에 데이터 통제가 중요한 환경에서도 도입 장벽이 낮다. 다만 공개된 수치가 전부 벤더 자체 측정이고 2.1 세부 정보의 1차 출처가 제한적이므로, 실제 코드베이스에서 재현 테스트를 거친 뒤 기존 코딩 어시스턴트와 비교하는 과정이 필요하다.

**관련 링크:** [llmreference.com](https://www.llmreference.com/model/mellum2-1-12b-thinking), [neowin.net](https://www.neowin.net/news/jetbrains-open-sources-mellum-2-featuring-12b-total-parameters/)

### 4. Microsoft와 Nvidia, 온디바이스 AI용 Surface Laptop Ultra 공개
**카테고리:** Hardware / On-device AI

**주요 내용:**
- Microsoft와 Nvidia가 고성능 Windows 노트북인 Surface Laptop Ultra를 공개했다. 정교한 AI 모델을 클라우드가 아닌 기기 내부에서 직접 구동하도록 설계됐다.
- 같은 주에 SpaceX가 Nvidia AI 칩 확보를 위해 약 400억 달러 규모의 자금 조달을 추진하고, SoftBank이 신규 AI 펀드를 위해 중동 투자자로부터 최대 1,000억 달러를 모집한다는 보도가 나오는 등, AI 하드웨어·인프라 투자 흐름이 함께 부각됐다.

**엔지니어 관점 포인트:**
소형 모델의 성능이 올라가고 Mellum 2.1 같은 로컬 구동 모델이 늘어나는 흐름과 맞물려, 온디바이스에서 제대로 된 모델을 돌릴 수 있는 하드웨어가 제품화되는 단계로 들어서고 있다. 로컬 추론이 보편화되면 지연과 데이터 프라이버시 측면의 이점이 커지고, 클라우드 호출을 전제로 짜던 애플리케이션 아키텍처에서 로컬·클라우드 하이브리드 설계를 고려할 유인이 생긴다. 현 시점에서는 구체적인 사양과 지원 모델 범위가 아직 충분히 공개되지 않았으므로, 실제 로컬 추론 성능은 출시 후 벤치마크를 확인할 필요가 있다.

**관련 링크:** [techstartups.com](https://techstartups.com/2026/10/09/top-ai-news-stories-this-week-october-5-9-2026)
