## 오늘의 핵심 AI 뉴스 요약

1. **제목:** Microsoft Agent Framework PyPI 공급망 사고, `1.26.1`·`1.26.2` 격리 필요
   **카테고리:** 보안·에이전트 인프라
   **주요 내용:**
   - GitHub Advisory Database는 2026-11-19(KST)에 `agent-framework`의 악성 릴리스 사실을 공개했다. 문제 버전은 2026-11-17에 배포된 `1.26.1`과 `1.26.2`이며, Python 시작 시 실행되는 `.pth` 훅이 환경 변수·자격 증명 파일·클라우드 토큰을 수집할 수 있었다.
   - 해당 버전은 PyPI에서 제거됐고, `1.26.0` 이하에는 영향이 없다고 안내됐다. 이는 새 기능 출시가 아니라 이미 배포된 패키지에 대한 공급망 사고 공지다.
   **엔지니어 관점 포인트:**
   - 잠금 파일, 패키지 캐시, CI 이미지, 개발 환경에서 두 버전의 설치 이력을 확인하고 영향 환경은 깨끗한 베이스로 재생성한다.
   - 노출 가능 환경에서 접근 가능한 클라우드·GitHub·Azure DevOps 자격 증명은 즉시 회전한다.
   **관련 링크:** [GitHub Advisory Database](https://github.com/advisories/GHSA-764m-3ppc-5m73)

2. **제목:** Google Gemini Interactions API, Tool Retrieval 프리뷰 공개
   **카테고리:** 모델 API·에이전트 도구 호출
   **주요 내용:**
   - 2026-11-19 Google은 `tool_search`와 `defer_loading: true`를 사용해 도구 이름·설명만 먼저 유지하고, 모델이 선택한 도구의 전체 스키마를 같은 요청 안에서 지연 로드하는 기능을 프리뷰로 공개했다.
   - 수십~수백 개 도구를 쓰는 에이전트의 입력 토큰과 도구 선택 부담을 줄이는 설계이며, 원격 MCP 서버와 클라이언트 측 검색(`execution: "client"`)도 지원한다. 로드된 스키마는 일반 입력 토큰으로 과금된다.
   **엔지니어 관점 포인트:**
   - 프리뷰 기능이므로 검색 누락, 권한 필터링, 모호한 도구 설명, 지연시간과 토큰 비용을 기존 eager-loading 방식과 함께 평가한다.
   - Gemini 3.6 이상 및 Gemini 4 대상 기능으로 안내된 만큼 모델·API 호환 범위를 고정하고, 프로덕션 도입 전 동작 변경 가능성을 감안한다.
   **관련 링크:** [Google: Introducing Tool Retrieval in the Gemini API](https://blog.google/innovation-and-ai/technology/developers-tools/gemini-api-tool-retrieval/)

3. **제목:** Microsoft Foundry, 주요 OpenAI 모델 2026-11-19 retire 적용
   **카테고리:** 모델 수명주기·클라우드 운영
   **주요 내용:**
   - Microsoft Foundry 수명주기 표(2026-11-18 업데이트)는 `o1`, `o1-pro`, `o3`, `o3-deep-research`, `o3-mini`, `o3-pro`, `o4-mini`의 retirement 적용일을 2026-11-19로 명시한다. 이는 새 모델 출시가 아니라 수명주기 표의 적용 시점이다.
   - 대부분의 대체 모델로 `gpt-5.6-sol`, `o3-mini`와 `o4-mini`에는 `gpt-5.6-terra`가 제시됐으며, `Llama-4-Maverick-17B-128E-Instruct-FP8`도 같은 날짜에 retire되고 대체 모델은 표에 없다.
   **엔지니어 관점 포인트:**
   - 애플리케이션 설정, 라우터·fallback 체인, 평가 fixture에 남은 모델 ID를 찾아 대체 모델로 회귀 테스트한다.
   - API 호환성만 확인하지 말고 도구 호출, 추론 품질, 지연시간과 비용이 달라지는지 검증한 뒤 단계적으로 전환한다.
   **관련 링크:** [Microsoft Learn: Model retirement schedule for Microsoft Foundry](https://learn.microsoft.com/en-us/azure/foundry/openai/concepts/model-retirement-schedule?view=foundry)

4. **제목:** OpenHands v1.42.0, 저장소·검증 워크플로 통합 개선
   **카테고리:** 오픈소스 에이전트·개발 도구
   **주요 내용:**
   - OpenHands v1.42.0은 2026-11-19 01:36:17(KST)에 공개됐다. 여러 Git 제공자가 연결된 환경에서 저장소를 정확히 선택하고, Verify OpenHands 실행에 비루프백 plain-HTTP origin을 부여한다.
   - 네이티브 webhook source 검증을 복원하고 Clipboard API fallback을 추가했다. 새 모델 출시는 아니며, 에이전트 실행·통합 경로를 다듬는 릴리스다.
   **엔지니어 관점 포인트:**
   - 버전 업 후 다중 Git provider 선택, Verify origin, webhook 검증과 클립보드 fallback을 포함한 통합 smoke test를 실행한다.
   - macOS Agent Canvas 앱은 Apple Developer ID 서명이 없어 Gatekeeper에서 “damaged”로 표시될 수 있으므로, 공식 workaround와 배포 정책을 확인한다.
   **관련 링크:** [OpenHands v1.42.0 release](https://github.com/OpenHands/OpenHands/releases/tag/v1.42.0)
