## 오늘의 핵심 AI 뉴스 요약

### 1. Anthropic, Claude Sonnet 5.5 공개
**카테고리:** LLM

**주요 내용:**
- Anthropic이 9월 28일 중형 모델 Claude Sonnet 5.5를 공개했다.
- 이전 Sonnet 세대 대비 출력 속도가 30% 이상 빨라졌고, 작업당 비용은 최대 30%까지 낮아졌다. 성능은 상위 모델인 Opus 5.5에 근접한 수준으로 발표됐다.

**엔지니어 관점 포인트:**
Sonnet 5.5의 핵심은 성능이 아니라 비용 대비 효율이다. Opus 5.5에 가까운 품질을 30% 저렴한 단가로 제공한다는 것은, 그동안 최상위 모델에 의존하던 코드 생성이나 에이전트 루프의 상당 부분을 Sonnet 급으로 내려도 품질 손실이 크지 않다는 뜻이다. 대량 호출이 발생하는 백엔드 파이프라인이나 RAG 서빙 계층에서는 모델 티어를 한 단계 낮추는 것만으로 월 추론 비용이 눈에 띄게 줄어들 수 있어, 실무에서는 벤치마크 점수보다 이런 단가 곡선의 변화가 아키텍처 결정에 더 직접적인 영향을 준다.

**관련 링크:** [AI Weekly - AI News Today](https://aiweekly.co/ai-news-today)

### 2. DeepSeek V4.1-Flash, MIT 라이선스로 오픈소스 공개
**카테고리:** Open Source

**주요 내용:**
- DeepSeek가 멀티모달 Mixture-of-Experts 구조의 V4.1-Flash를 MIT 라이선스로 HuggingFace에 공개했다. 백본 기준 5,520억 파라미터 규모이며, 약 45조 토큰으로 학습됐다.
- 자체 발표 기준 DeepSWE v1.1, CyberGym, Automation-Bench에서 Anthropic Opus 5와 OpenAI GPT-5.6-Sol을 앞섰고, Terminal Bench 3.0에서는 뒤처졌다.
- Causal Encoder-Decoder, Compressed Sparse Attention 2, FP4 KV 캐싱 등 추론 비용과 메모리 사용을 줄이는 구조적 변경이 적용됐다.

**엔지니어 관점 포인트:**
MIT 라이선스라는 점이 가장 큰 실무적 의미를 갖는다. 가중치를 내려받아 수정하고 파인튜닝한 뒤 상업적으로 재배포하는 데 별도 허가나 비용이 필요 없기 때문에, 데이터 반출이 곤란한 온프레미스 환경이나 자체 서빙을 고려하던 팀에게 현실적인 선택지가 된다. FP4 KV 캐싱과 희소 어텐션은 동일 GPU 메모리에서 더 긴 컨텍스트를 다루거나 더 많은 동시 요청을 처리할 수 있게 해주므로, 자체 인프라의 처리량 단가를 계산할 때 눈여겨볼 만하다. 다만 벤치마크는 자체 발표 수치이므로 도입 전 자사 태스크 기준의 검증이 필요하다.

**관련 링크:** [DeepSeek 공식 발표](https://www.deepseek.com/en/news/deepseek-v4-1-flash/)

### 3. Microsoft Agent Framework, BUILD 2026에서 대규모 업데이트
**카테고리:** Agentic AI

**주요 내용:**
- Microsoft가 BUILD 2026에서 Agent Framework에 Agent Harness, Hosted Agents, CodeAct 등을 추가한다고 발표했다.
- 에이전트를 개발 단계의 프로토타입에서 운영 환경에 배포 가능한 형태로 끌어올리는 데 초점을 맞췄다.

**엔지니어 관점 포인트:**
올해 에이전트 관련 발표들의 공통 흐름은 개념 증명에서 프로덕션으로의 이동이다. Hosted Agents는 에이전트 실행 환경을 직접 구축하고 운영하는 부담을 줄여주고, CodeAct 방식은 에이전트가 자연어 도구 호출 대신 코드를 생성해 실행하도록 해 복잡한 다단계 작업의 안정성을 높인다. 자체 오케스트레이션 로직을 처음부터 짜던 팀이라면, 이런 표준화된 하네스가 상태 관리와 재시도, 관측성 같은 반복적으로 재발명되던 부분을 흡수해줄 수 있는지 검토할 시점이다.

**관련 링크:** [Microsoft Agent Framework 블로그](https://devblogs.microsoft.com/agent-framework/microsoft-agent-framework-at-build-2026-announce/)

### 4. LangGraph 1.2, CrewAI A2A 등 에이전트 프레임워크 성숙 단계 진입
**카테고리:** Developer Tool

**주요 내용:**
- LangGraph가 1.2 마일스톤에 도달하며 durable execution과 상태 유지 워크플로우를 강화했다. 장시간 유지되는 복잡한 에이전트 프로세스를 위한 기능이다.
- CrewAI는 Agent-to-Agent(A2A) 연동이 엔터프라이즈 수준에 도달해 다중 에이전트가 통신하는 프로덕션 시나리오에 적합해졌다고 밝혔다.
- Google도 Gemini API의 managed agents에 Antigravity 코딩 에이전트의 도구와 동작을 가져오는 새 하네스를 추가했다.

**엔지니어 관점 포인트:**
에이전트 프레임워크 경쟁이 기능 나열에서 신뢰성으로 옮겨가고 있다. LangGraph의 durable execution은 프로세스가 중간에 끊겨도 상태를 복원해 이어갈 수 있게 해주는데, 이는 수 시간짜리 장기 작업이나 사람 승인을 기다리는 워크플로우에서 필수적이다. 여러 프레임워크가 A2A 같은 에이전트 간 통신 표준으로 수렴하는 흐름은, 특정 벤더에 종속되지 않는 멀티 에이전트 설계가 가능해지고 있음을 시사한다. 도입을 검토한다면 화려한 데모보다 장애 복구와 상태 지속성 지원 여부를 먼저 확인하는 편이 낫다.

**관련 링크:** [AI Agent 프레임워크 비교](https://www.morphllm.com/ai-agent-framework)

### 5. OpenAI 연 환산 매출 약 700억 달러 규모 도달
**카테고리:** Industry

**주요 내용:**
- OpenAI의 연 환산 매출 실행률(run rate)이 3분기 초 대비 70% 이상 증가해 약 700억 달러에 도달했다.
- 같은 기간 B2B 매출은 두 배 이상으로 늘었다.

**엔지니어 관점 포인트:**
숫자 자체보다 B2B 매출이 두 배로 늘었다는 구성 변화가 의미 있다. AI가 개별 사용자의 챗봇 소비를 넘어 기업 업무 시스템에 실제로 통합되고 있다는 신호이기 때문이다. 이는 곧 API 가용성, 요금 정책, 엔터프라이즈 기능(감사 로그, 데이터 처리 계약, SLA)에 대한 공급사의 투자 우선순위가 개인 소비자에서 기업 고객 쪽으로 이동한다는 뜻이기도 하다. 특정 공급사에 의존하는 서비스를 운영 중이라면, 급격한 성장기의 요금·정책 변동 가능성을 아키텍처 차원의 리스크로 관리해둘 필요가 있다.

**관련 링크:** [AI Weekly - AI News Today](https://aiweekly.co/ai-news-today)
