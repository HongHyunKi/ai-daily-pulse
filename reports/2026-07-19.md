### 1. Moonshot AI, 역대 최대 오픈 웨이트 모델 Kimi K3 공개
**카테고리:** Open Source / LLM

**주요 내용:**
- 중국 Moonshot AI가 7월 16일 2.8조(2.8T) 파라미터 규모의 오픈 웨이트 멀티모달 추론 모델 Kimi K3를 공개했다. 역대 공개된 오픈 웨이트 모델 중 최대 규모다.
- 896개의 expert 중 토큰당 16개만 활성화되는 희소 MoE 구조로, 전체 네트워크의 약 1.8%만 사용해 추론 비용을 낮췄다. 컨텍스트 윈도우는 1,048,576 토큰이다.
- Arena의 Frontend Code 평가에서 1,679점으로 1위에 올라 Claude Fable 5를 앞섰고, GDPval-AA v2에서는 전체 3위를 기록했다. 현재는 API로만 제공되며 전체 가중치는 7월 27일까지 공개될 예정이다.

**엔지니어 관점 포인트:**
프론트엔드 코드 생성이라는 특정 영역에서 오픈 웨이트 모델이 최상위 클로즈드 모델을 블라인드 평가로 앞선 것은 처음에 가까운 사건이다. 전체 성능에서는 여전히 Fable 5와 GPT-5.6 Sol에 뒤지지만, 코딩·에이전트 벤치마크에서 Claude Opus 4.8을 넘어섰다는 점은 셀프 호스팅이나 파인튜닝을 고려하는 팀에게 실질적인 선택지가 생겼음을 의미한다. 미국의 컴퓨트 제재 속에서 중국 랩이 3T급 모델을 오픈 웨이트로 내놓았다는 사실 자체도 인프라 전략 관점에서 눈여겨볼 대목이다. 7월 27일 가중치 공개 이후 실제 서빙 비용과 양자화 커뮤니티의 대응을 지켜볼 필요가 있다.

**관련 링크:** [VentureBeat](https://venturebeat.com/technology/chinas-moonshot-ai-releases-kimi-k3-the-largest-open-source-model-ever-rivaling-top-u-s-systems), [Tom's Hardware](https://www.tomshardware.com/tech-industry/artificial-intelligence/moonshot-releases-2-8-trillion-parameter-kimi-k3)

### 2. Thinking Machines, 첫 오픈 웨이트 모델 Inkling 출시
**카테고리:** Open Source / LLM

**주요 내용:**
- Mira Murati가 이끄는 Thinking Machines Lab이 7월 15일 첫 오픈 웨이트 멀티모달 모델 Inkling을 출시했다. 총 975B 파라미터, 토큰당 41B만 활성화되는 희소 MoE 구조다.
- 텍스트·이미지·오디오·비디오를 포함한 45조 토큰으로 사전학습했고, 텍스트·이미지·오디오 입력을 받아 텍스트를 출력하는 네이티브 멀티모달 모델이다. 컨텍스트는 최대 100만 토큰을 지원한다.
- 개발자가 답변 전 연산량을 조절할 수 있는 controllable reasoning 시스템을 탑재했다. 가중치는 HuggingFace에서 받을 수 있고, 자사 Tinker 플랫폼 API로도 제공된다. 12B 활성 파라미터의 Inkling-Small 프리뷰도 함께 공개됐다.

**엔지니어 관점 포인트:**
Inkling의 핵심 포지셔닝은 "커스터마이징 가능한 파운데이션 모델"이다. 처음부터 파인튜닝을 전제로 설계해 전체 가중치 접근을 제공한다는 점에서, API 뒤에 잠긴 범용 모델과 다른 노선을 택했다. 미국발 오픈 웨이트 모델 중 최상위 성능이라는 평가(Artificial Analysis)가 나오는 만큼, 지금까지 중국 모델들이 주도해온 오픈 웨이트 경쟁 구도에 미국 랩이 본격적으로 합류한 셈이다. 추론 강도를 코드로 제어할 수 있어 지연 시간과 토큰 비용을 워크로드별로 최적화하기 좋고, 도메인 특화 모델을 자체 구축하려는 팀이라면 Tinker 파인튜닝 스택과 함께 검토할 가치가 있다.

**관련 링크:** [Thinking Machines Lab](https://thinkingmachines.ai/news/introducing-inkling/), [Artificial Analysis](https://artificialanalysis.ai/articles/thinking-machines-has-released-inkling-the-new-leading-u-s-open-weights-model)

### 3. MCP 2026-07-28 릴리스 후보: 프로토콜 코어가 stateless로 전환
**카테고리:** Developer Tool / Protocol

**주요 내용:**
- Model Context Protocol(MCP)의 차기 사양 릴리스 후보가 공개됐다. 최종 사양은 7월 28일 확정된다.
- 가장 큰 변화는 stateless 코어 전환이다. initialize/initialized 핸드셰이크와 Mcp-Session-Id 헤더가 제거되고, 프로토콜 버전·클라이언트 정보·capabilities가 각 요청의 _meta 필드에 인라인으로 실린다. 원격 MCP 서버를 일반 라운드로빈 로드밸런서 뒤에서 운영할 수 있고, 클라이언트는 tools/list 응답을 서버가 허용한 ttlMs만큼 캐시할 수 있다.
- 서버 렌더링 UI를 위한 MCP Apps, 장기 실행 작업을 위한 Tasks 확장이 추가된다. Roots, Sampling, Logging 세 기능은 deprecation에 들어가며, 폐기까지 최소 12개월 유예를 보장하는 공식 deprecation 정책이 도입됐다.

**엔지니어 관점 포인트:**
MCP 서버를 프로덕션에 배포해본 팀이라면 sticky session과 세션 스토어가 얼마나 성가신 요구사항이었는지 알 것이다. 이번 변경으로 MCP 서버가 일반 REST API와 동일한 방식으로 수평 확장 가능해져, 서버리스나 쿠버네티스 환경 배포 장벽이 크게 낮아진다. 다만 핸드셰이크 제거는 기존 구현에 breaking change이므로, 자체 MCP 서버나 클라이언트를 운영 중이라면 SDK 마이너 업데이트 추적과 함께 10주 검증 기간 내 대응 계획을 세워두는 것이 좋다. Sampling과 Logging의 deprecation 방향(LLM API 직접 호출, stderr/OpenTelemetry 사용)도 설계에 미리 반영해둘 부분이다.

**관련 링크:** [MCP Blog](https://blog.modelcontextprotocol.io/posts/2026-07-28-release-candidate/), [Medium (Fmind)](https://fmind.medium.com/mcp-2026-07-28-stateless-core-enterprise-authorization-and-sdk-betas-2646a980d594)

### 4. Microsoft, 멀티 모델 AI 보안 제품 Project Perception 발표
**카테고리:** Enterprise AI / Security

**주요 내용:**
- Microsoft가 Anthropic, OpenAI, 자사 모델을 함께 사용하는 멀티 모델 AI 보안 제품 Project Perception을 출시한다.
- 특정 랩의 단일 모델에 의존하지 않고 작업 특성에 따라 여러 프론티어 모델을 조합하는 구조로, Anthropic의 Mythos 5 대비 저렴한 대안으로 포지셔닝했다.
- Microsoft의 글로벌 엔터프라이즈 유통망을 활용해 단일 모델 벤더가 따라오기 어려운 배포 범위를 확보하겠다는 전략이다.

**엔지니어 관점 포인트:**
주목할 지점은 보안 제품 자체보다 "멀티 모델 오케스트레이션"이 엔터프라이즈 제품의 기본 아키텍처로 자리잡고 있다는 흐름이다. Microsoft가 자사 모델만 고집하지 않고 경쟁사인 Anthropic과 OpenAI 모델을 함께 태우는 것은, 단일 모델의 성능 우위보다 라우팅·비용·유통이 제품 경쟁력을 결정한다는 판단으로 읽힌다. 애플리케이션 레이어에서 모델을 추상화하고 작업별로 최적 모델에 라우팅하는 설계는 이제 보안 도메인까지 확장됐고, 사내 AI 시스템을 설계할 때도 특정 벤더 종속을 피하는 모델 추상화 레이어를 고려할 이유가 하나 더 늘었다.

**관련 링크:** [BuildFastWithAI](https://www.buildfastwithai.com/blogs/ai-news-today-july-18-2026)

## 오늘의 트렌드 한눈에 보기
이번 주 흐름을 관통하는 키워드는 오픈 웨이트 경쟁의 본격화와 인프라 표준의 성숙이다. Moonshot AI의 Kimi K3와 Thinking Machines의 Inkling이 며칠 간격으로 출시되면서, 오픈 웨이트 모델이 특정 벤치마크에서 최상위 클로즈드 모델과 대등하거나 앞서는 국면에 들어섰다. 중국 랩이 규모로, 미국 신생 랩이 커스터마이징 가능성으로 각자 다른 각도에서 클로즈드 모델의 해자를 공략하는 모양새다. 한편 MCP의 stateless 전환은 에이전트 생태계가 실험 단계를 지나 일반 웹 인프라 위에서 운영되는 표준 기술로 정착하고 있음을 보여주며, Microsoft의 멀티 모델 보안 제품은 애플리케이션 레이어에서 모델을 조합하고 라우팅하는 설계가 엔터프라이즈의 기본값이 되고 있다는 신호다. 개발자 입장에서는 특정 모델·벤더에 종속되지 않는 추상화 설계와 오픈 웨이트 모델의 실전 투입 가능성을 동시에 검토할 시점이다.
