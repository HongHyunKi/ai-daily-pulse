# Daily AI Pulse: 2026-07-28

## 오늘의 핵심 AI 뉴스 요약

### 1. MCP 2026-07-28 스펙 확정, 세션 제거하고 스테이트리스로 전환

**카테고리:** Developer Tool / Protocol

**주요 내용:**
- Model Context Protocol(MCP) 유지보수팀이 오늘 2026-07-28 리비전을 최종 확정했으며, 출시 이후 인증 도입에 버금가는 가장 큰 폭의 변경이다.
- 프로토콜 레벨의 세션과 initialize 핸드셰이크가 제거되어 코어가 스테이트리스(stateless)로 바뀌었고, 인증(authorization) 방식이 재작성됐으며 확장(extension) 프레임워크가 새로 도입됐다.
- 기존 3개 핵심 기능이 deprecated 처리됐고, 표시된 기능은 최소 12개월간 동작을 유지하지만 신구 클라이언트 간 상호운용성은 보장되지 않는다.

**엔지니어 관점 포인트:**
세션과 sticky 연결이 사라지면서 그동안 원격 MCP 서버 운영에 필요했던 공유 세션 스토어와 게이트웨이의 심층 패킷 검사가 불필요해졌다. 이제 일반적인 라운드로빈 로드밸런서 뒤에 MCP 서버를 배치할 수 있어, 에이전트 인프라의 수평 확장과 운영 복잡도 측면에서 실질적인 개선이 기대된다. 다만 하위 호환이 깨지는 변경이 포함된 만큼, 기존 서버·클라이언트를 운용 중인 팀은 SDK 베타로 마이그레이션 경로를 미리 검증하고 deprecated 기능 의존도를 점검해 두는 것이 안전하다.

**관련 링크:** [Model Context Protocol Blog](https://blog.modelcontextprotocol.io/posts/2026-07-28-release-candidate/)

### 2. Moonshot AI, 역대 최대 오픈웨이트 모델 Kimi K3 공개

**카테고리:** Open Source / LLM

**주요 내용:**
- Moonshot AI가 2.8조(2.8T) 파라미터 규모의 Mixture-of-Experts 모델 Kimi K3의 가중치를 Hugging Face에 공개했다. 예고된 7월 27일보다 하루 앞선 7월 26일에 배포됐으며, 공개된 오픈웨이트 모델 중 역대 최대 규모다.
- 100만 토큰 컨텍스트와 네이티브 비전을 지원하고 Intelligence Index에서 57점을 기록해, 클로즈드 모델인 GPT-5.6 Sol에 근접한 성능을 보였다.
- 어텐션 커널과 MoE 라이브러리 등 부속 도구도 함께 오픈소스로 공개됐으며, Together AI와 Modal이 day-0 호스팅을 지원한다.

**엔지니어 관점 포인트:**
프론티어급 성능의 오픈웨이트 모델이 현실이 됐다는 점에서 의미가 크다. 자체 호스팅이 가능해지면서 데이터를 외부 API로 보내지 않고도 최상위권 모델을 운용할 수 있는 선택지가 생겼다. 다만 가중치 용량이 약 1.4TB에 달해 실제 셀프 호스팅에는 상당한 인프라 비용과 추론 최적화가 요구되며, 라이선스가 대형 제공업체에는 별도 상용 계약을 요구한다는 점도 도입 전 확인이 필요하다.

**관련 링크:** [Interconnects - Kimi K3: The open-weights escalation](https://www.interconnects.ai/p/kimi-k3-the-open-weights-escalation)

### 3. Anthropic, Claude Opus 5 출시

**카테고리:** LLM

**주요 내용:**
- Anthropic이 7월 24일 Claude Opus 5를 출시하며 이달 후반 모델 라인업을 확장했다.
- 앞서 이달 초 Claude Sonnet 5와 최상위 Mythos급 프론티어 모델 Claude Fable 5가 공개된 데 이어 나온 상위 티어 릴리스다.

**엔지니어 관점 포인트:**
Sonnet과 Fable에 이어 Opus 5까지 더해지면서 Claude 제품군이 비용과 성능 축에서 촘촘하게 재편됐다. 코딩·에이전트 워크플로우를 운영하는 팀은 작업 난이도와 예산에 맞춰 티어를 선택할 여지가 넓어졌다. 실제 도입 시에는 벤치마크 수치보다 자사 파이프라인에서의 지연시간과 토큰 단가, 그리고 기존 프롬프트·툴 정의의 호환성을 기준으로 티어를 검증하는 접근이 합리적이다.

**관련 링크:** [LLM Release Timeline](https://llmgateway.io/timeline)

### 4. OpenAI, GPT-5.6 패밀리 Luna/Terra/Sol 공개

**카테고리:** LLM / Agentic AI

**주요 내용:**
- OpenAI가 Luna, Terra, Sol 세 가지 크기로 구성된 GPT-5.6 플래그십 모델 패밀리를 발표했다. 입력 토큰 기준 100만 토큰당 1~5달러 가격대이며, 세 모델 모두 100만 토큰 컨텍스트 윈도우와 2026년 2월 지식 컷오프를 갖췄다.
- 프로그래밍 방식 도구 호출(programmatic tool calling), 멀티 에이전트 오케스트레이션, 프롬프트 캐시 브레이크포인트 등 새로운 API 기능이 함께 도입됐다.
- 장기 실행 에이전트 벤치마크에서 Claude Fable 5를 앞선다는 평가가 보고됐다.

**엔지니어 관점 포인트:**
가격과 크기를 나눈 3종 구성은 에이전트 파이프라인에서 작업별로 모델을 분기해 비용을 최적화하기 좋은 구조다. 특히 프로그래밍 방식 도구 호출과 멀티 에이전트 오케스트레이션, 프롬프트 캐시 브레이크포인트는 복잡한 에이전트 시스템의 제어 흐름과 비용 관리를 API 레벨에서 다룰 수 있게 해준다. 장기 실행 에이전트 성능이 강조된 만큼, 단발성 질의응답보다 다단계 도구 사용 시나리오에서 실효성을 검증하는 것이 이 릴리스의 가치를 판단하는 핵심이 될 것이다.

**관련 링크:** [LLM News - llm-stats.com](https://llm-stats.com/ai-news)

## 오늘의 트렌드 한눈에 보기

오늘의 흐름은 크게 두 축으로 정리된다. 하나는 오픈웨이트 진영의 급속한 추격이다. Kimi K3가 2.8조 파라미터로 역대 최대 오픈웨이트 기록을 세우며 클로즈드 프론티어 모델과의 격차를 좁혔고, 프론티어급 성능을 자체 호스팅할 수 있는 현실적 선택지가 열렸다. 다른 하나는 모델 자체보다 그 모델을 엮어 쓰는 인프라 계층의 성숙이다. MCP 2026-07-28 스펙이 세션을 걷어내고 스테이트리스로 전환하면서 에이전트 서버의 배포와 확장이 단순해졌고, OpenAI GPT-5.6이 프로그래밍 방식 도구 호출과 멀티 에이전트 오케스트레이션을 API에 담아냈다. 정리하면 개발자에게 중요한 변화는 "더 똑똑한 모델 하나"가 아니라, 모델 선택지가 오픈·클로즈드 양쪽에서 넓어지는 동시에 그것들을 실제 프로덕션 에이전트로 조립하는 표준과 도구가 함께 빠르게 정비되고 있다는 점이다.
