### 1. GitHub Agentic Workflows 정식 출시, Markdown으로 Actions 자동화 정의

* **카테고리:** Open Source / Agentic AI / Developer Tool
* **주요 내용:**
  - GitHub가 10월 28일 GitHub Next의 오픈소스 프로젝트인 Agentic Workflows의 정식 출시를 발표했습니다. 자연어로 작성한 Markdown을 표준 GitHub Actions YAML로 컴파일해 실행합니다.
  - 이슈 분류, CI 실패 분석, 문서 수정, 테스트 작성처럼 판단이 필요한 작업을 기존 Actions 환경에서 자동화할 수 있습니다. GitHub Copilot 또는 다른 코딩 에이전트를 실행 엔진으로 선택할 수 있습니다.
  - 읽기 전용 권한 기본값, 샌드박스·방화벽, safe outputs 검증, 변경 적용 전 위협 탐지와 Cloud Hypervisor/NVX micro-VM 기반 격리 기능을 제공합니다.
* **엔지니어 관점 포인트:**
  - 별도의 에이전트 운영 서버를 만들기 전에 기존 CI에서 실패 분석이나 이슈 분류부터 시험할 수 있습니다. 쓰기 작업으로 확장할 때는 권한 범위, 검토 지점, 비용 예산을 워크플로우별로 고정하는 편이 안전합니다.
* **관련 링크:** [GitHub 공식 발표](https://github.blog/changelog/2026-10-28-github-agentic-workflows-generally-available/)

### 2. GitHub Copilot SDK, Microsoft Copilot SDK로 확장

* **카테고리:** Agentic AI / Developer Platform
* **주요 내용:**
  - Microsoft가 10월 28일 GitHub Copilot SDK를 Microsoft Copilot SDK로 전환한다고 발표했습니다. GitHub Copilot용 하네스에서 Microsoft와 GitHub 제품 전반의 공통 에이전트 기반을 프로그래밍하는 인터페이스로 역할을 넓히는 방향입니다.
  - 개발자는 프롬프트, 도구, 정책과 사용자 경험을 직접 통제하면서 Microsoft 제품과 같은 기반 위에 에이전트 경험을 만들 수 있게 됩니다.
  - 전환은 단계적으로 진행되며, 기존 패키지명·네임스페이스·일부 문서는 당분간 유지됩니다. 기존 사용자에게 즉시 필요한 변경은 없습니다.
* **엔지니어 관점 포인트:**
  - 장기적으로는 특정 제품에 종속된 코딩 에이전트 SDK보다 조직용 에이전트 하네스와 도구·정책 계층을 재사용하는 구조에 가까워집니다. 다만 지금은 이름 변경만을 이유로 마이그레이션하기보다 공식 저장소와 패키지 공지를 확인하며 종속성을 관리하면 됩니다.
* **관련 링크:** [GitHub 공식 변경 안내](https://github.blog/changelog/2026-10-28-github-copilot-sdk-is-becoming-microsoft-copilot-sdk/)

### 3. NVIDIA Nemotron 3.5 Transcribe 공개, 프롬프트 가능한 다국어 음성 모델과 학습 데이터 제공

* **카테고리:** Open Weights / Speech AI / Developer Tool
* **주요 내용:**
  - NVIDIA가 10월 28일 Nemotron 3.5 Transcribe를 공개했습니다. 하나의 오픈 가중치 체크포인트로 음성 인식, 화자 구분, 번역, 오디오 질의응답을 수행하며 40개 언어를 전사하고 31개 언어와 영어 사이의 번역을 지원합니다.
  - 최대 한 시간 녹음과 최대 8명 화자 처리를 지원하고, 자연어 프롬프트로 출력 형식과 도메인 용어를 지정할 수 있습니다. vLLM과 NeMo Speech.cpp 실행 경로를 제공합니다.
  - 함께 공개된 Granary v2는 48개 언어·16개 소스의 약 463,062시간 분량을 다루는 재사용 가능한 데이터 큐레이션 파이프라인과 전사 변형, 번역·질의응답·코드 스위칭용 메타데이터를 제공합니다.
* **엔지니어 관점 포인트:**
  - 회의·콜센터·미디어 파이프라인에서 전사, 화자 라벨링, 번역을 여러 모델로 이어 붙이는 대신 하나의 체크포인트로 비교할 수 있습니다. 다만 모델은 실시간 스트리밍용이 아니며, OpenMDW-1.1 라이선스와 언어·작업별 지원 범위를 실제 배포 전에 확인해야 합니다.
* **관련 링크:** [Hugging Face의 NVIDIA 공식 발표](https://huggingface.co/blog/nvidia/nemotron-transcribe-granary), [공식 모델 카드](https://huggingface.co/nvidia/NVIDIA-Nemotron-3.5-Transcribe-30B-A4B)

### 4. Apple 플랫폼용 AnySpeechRecognizer·AnyDecisionModel 공개

* **카테고리:** Open Source / On-device AI / Developer Tool
* **주요 내용:**
  - Hugging Face와 오픈소스 개발자 생태계가 10월 29일 Apple의 SpeechAnalyzer API를 유지하면서 음성 인식 엔진을 바꿔 끼울 수 있는 AnySpeechRecognizer와, 확률을 포함한 typed 결과를 반환하는 AnyDecisionModel을 공개했습니다.
  - AnySpeechRecognizer는 Parakeet·Qwen3-ASR을 Core ML로 기기에서 실행하고 화자 분리를 추가합니다. AnyDecisionModel은 MLX, Core AI, llama.cpp, Jev, Ollama 등의 백엔드로 예·아니오, 선택, 점수 결과와 확률을 제공합니다.
  - Swift 6.2 이상과 macOS 26/iOS 26 이상이 필요하며, 현재 AnyDecisionModel의 Core AI trait와 AnySpeechRecognizer는 의존성 버전 충돌로 함께 사용할 수 없습니다.
* **엔지니어 관점 포인트:**
  - 음성 입력과 간단한 분류·라우팅을 서버 왕복 없이 처리하려는 Apple 앱에서 모델 교체와 로컬 실행을 실험하기 쉬워졌습니다. 확률은 정답 보장이 아니므로 자체 데이터로 보정·임계값을 검증하고, 기기별 메모리와 모델 다운로드 크기를 측정해야 합니다.
* **관련 링크:** [Hugging Face 공식 발표](https://huggingface.co/blog/anydecisionmodel), [AnySpeechRecognizer GitHub](https://github.com/mattt/AnySpeechRecognizer), [AnyDecisionModel GitHub](https://github.com/mattt/AnyDecisionModel)

### 5. Project ProtoStar 출범, 공개 과학 데이터를 AI-ready 형식으로 재사용

* **카테고리:** Open Science / Open Data / AI Infrastructure
* **주요 내용:**
  - Hugging Face, CMU·Purdue·Georgia Tech·Arizona State University·George Washington University 등과 ORCA가 10월 29일 Project ProtoStar를 발표했습니다. 공공 연구의 데이터셋·모델·코드를 기계가 읽고 재사용하기 쉬운 형식으로 공개하는 이니셔티브입니다.
  - 단순 공개에 그치지 않고 문서화, 메타데이터, provenance와 상호운용성 문제를 다루며, AI-ready 과학 자원을 실제로 조합해 보는 공개 챌린지를 진행합니다.
  - 첫 챌린지는 CMU가 주최하는 도시 기후 위험 예측으로 11월 2~13일 진행되며, 210개 미국 도시의 과거 기상자료로 2019~2026년 실제 조건을 예측하고 통계적 기준선과 비교합니다.
* **엔지니어 관점 포인트:**
  - 모델 성능보다 데이터의 발견성·재현성·provenance가 병목인 과학·RAG 프로젝트에서 공용 데이터 계약의 사례가 될 수 있습니다. 데이터를 가져다 쓸 때는 문서화 수준, 원본 라이선스, 스키마와 평가 기준을 함께 버전 관리해야 합니다.
* **관련 링크:** [Hugging Face 공식 발표](https://huggingface.co/blog/announcing-project-protostar)
