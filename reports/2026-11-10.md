### 1. Baidu, ERNIE Evolve 공개 — AI가 코드 수정·실험·평가를 반복하는 자동 연구 시스템
* **카테고리:** Agentic AI / AI Infrastructure
* **주요 내용:**
  - Baidu ERNIE 팀이 11월 9일, 명시적인 목표와 제약 아래 연구 방향을 고르고 코드를 수정한 뒤 격리 환경에서 실험하는 자동 연구 시스템 ERNIE Evolve를 공개했다.
  - 시스템은 연구 방향을 정하는 외부 루프와 각 방향의 후보 코드를 반복 개선하는 내부 루프로 구성되며, 독립 평가와 리뷰를 통과한 변경만 유지한다.
  - 공개 AI 연구 과제뿐 아니라 ERNIE-5.5-Flash의 실제 추론 최적화에도 적용했으며, 정확성·결정성·부하 테스트를 포함한 운영 검증을 통과했다고 Baidu는 설명했다.
* **엔지니어 관점 포인트:**
  - 에이전트의 역할이 코드 생성에서 끝나지 않고, 가설 수립·실험 실행·노이즈 판별·변경 채택까지 이어지는 연구 루프로 확장되고 있다.
  - 이런 시스템을 도입하려면 모델보다 평가 프로그램의 독립성, 재현 가능한 실험 환경, 변경 이력과 실패 원인의 저장이 핵심이다. 자동화 범위가 넓어질수록 권한·자원·중단 조건을 먼저 설계해야 한다.
* **관련 링크:** [ERNIE Evolve: Toward Automated Research for Real-World AI R&D](https://ernie.baidu.com/research/posts/ernie-evolve/)

### 2. GitHub Agentic Workflows v1.2.1 — 에이전트 작업의 중단·재개와 보안 검증 강화
* **카테고리:** Agentic AI / Developer Tool
* **주요 내용:**
  - GitHub가 11월 9일 주간 업데이트에서 Agentic Workflows v1.2.1을 소개했다. 아티팩트 기반 durable continuation으로 한 에이전트의 작업을 다음 에이전트가 이어받을 수 있다.
  - 사양을 인식하는 PR 리뷰어, 실험적 Atomic 선언형 엔진, 저장소 메모리용 GitHub App 인증, 배포 환경 제어가 추가됐다.
  - 보안 리뷰가 미해결 상태에서 실패하도록 바뀌었고, 동적 checkout ref에 대한 경고와 더 안전한 업데이트 동작이 포함됐다. v1.2.0에서는 fork의 `pull_request_target` 사용에 명시적 opt-in을 요구하기 시작했다.
* **엔지니어 관점 포인트:**
  - 장시간 에이전트 작업을 일회성 실행이 아니라 상태를 남기고 재개하는 워크플로우로 운영할 수 있는 기반이 마련됐다.
  - 다만 durable execution은 저장되는 아티팩트와 복구 시 재실행되는 권한을 함께 점검해야 한다. fork PR, checkout ref, 시크릿 전달 경로를 기존 CI 권한 모델과 분리해 검토할 필요가 있다.
* **관련 링크:** [Weekly Update – November 9, 2026](https://github.github.com/gh-aw/blog/2026-11-09-weekly-update/)

### 3. Claude Agent ACP v0.101.1 릴리스 — 백그라운드 작업과 ACP v2 상호운용성 보강
* **카테고리:** Developer Tool / Agent Protocol
* **주요 내용:**
  - Claude Agent ACP가 11월 9일 v0.101.1을 릴리스했다.
  - autonomous turn의 후속 idle 상태를 유지하고, 재개된 세션의 모델 정보를 노출하며, 서브에이전트의 백그라운드 Bash 명령과 Monitor 호출을 세션 작업으로 전달한다.
  - ACP v2의 워크플로우 도구 카드·진행 상태 렌더링을 보완하고, 최신 Agent Client Protocol SDK 2.5.0과 Claude Agent SDK 0.3.319를 반영했다.
* **엔지니어 관점 포인트:**
  - 코딩 에이전트를 IDE·터미널·자동화 서비스 사이에서 연결할 때 필요한 세션 수명, 백그라운드 작업, 진행 상태의 공통 표현이 구체화되고 있다.
  - ACP 클라이언트는 v2만 가정하기보다 v1과의 협상·하위 호환을 유지하고, 재개·취소·백그라운드 작업의 상태 전이를 idempotent하게 처리해야 한다.
* **관련 링크:** [claude-agent-acp v0.101.1 release](https://github.com/agentclientprotocol/claude-agent-acp/releases/tag/v0.101.1)

### 4. CoreWeave와 Wayve, Blackwell 기반 AI Driver 학습 협약 발표
* **카테고리:** AI Infrastructure / Physical AI
* **주요 내용:**
  - CoreWeave와 Wayve가 11월 9일 다년간의 협약을 발표했다. Wayve는 자율주행용 AI Driver 파운데이션 모델의 학습·평가·시뮬레이션을 NVIDIA Blackwell GPU 기반 CoreWeave Cloud에서 확장한다.
  - Wayve는 지도와 차량 하드웨어에 덜 종속적인 end-to-end embodied AI를 개발하고 있으며, 이번 협약은 상용 배포를 앞둔 학습·검증 인프라 확대에 초점을 둔다.
* **엔지니어 관점 포인트:**
  - 물리 세계를 다루는 모델은 학습 규모만큼 시뮬레이션, 평가, 안전 검증을 반복할 수 있는 인프라가 중요하다. 일반적인 LLM 학습 클러스터와 달리 데이터·시뮬레이터·하드웨어 루프가 함께 설계되어야 한다.
  - 개발팀은 GPU 종류보다 재현 가능한 평가 파이프라인, 실패 시나리오의 데이터화, 실제 배포 전 검증 기준을 먼저 확인해야 한다.
* **관련 링크:** [CoreWeave to Power Wayve's AI Driver Training in Multi-Year Agreement](https://coreweave.com/news/coreweave-to-power-wayves-ai-driver-training-in-multi-year-agreement)
