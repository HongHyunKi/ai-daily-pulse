### 1. 엔비디아, 단일 GPU에서 도는 오픈소스 에이전트 모델 Nemotron 3.5 Lightning 공개
**카테고리:** Open Source / Agentic AI

**주요 내용:**
- 엔비디아가 300억 파라미터(활성 파라미터 30억)의 오픈소스 모델 Nemotron 3.5 Lightning을 공개했다. Mamba-2와 MoE, 어텐션을 결합한 하이브리드 구조에 1M 토큰 컨텍스트를 지원한다.
- 토큰당 30억 파라미터만 활성화하는 MoE 설계 덕분에 RTX PC나 DGX Spark 같은 소비자용 단일 GPU에서 구동할 수 있다. 상위 모델인 Nemotron 3 Ultra에서 증류(distillation)한 모델로, 동급 오픈 모델 대비 출력 속도가 최대 4배 빠르고 에이전트 작업 완료는 약 30% 더 빠르다고 밝혔다.
- OpenMDW-1.1 라이선스로 가중치, 학습 데이터, 레시피가 함께 공개됐으며 상업적 이용도 허가 없이 무료다. 요청을 가장 효율적인 모델로 라우팅하는 오픈소스 라이브러리 NeMo Switchyard도 함께 나왔다.

**엔지니어 관점 포인트:**
클라우드 API 호출 없이 로컬 단일 GPU에서 장시간 에이전트 워크로드를 돌릴 수 있다는 점이 실무적으로 가장 큰 변화다. 코드 리뷰, 툴 호출, 보안 알림 모니터링처럼 반복적이고 대량으로 발생하는 특화 작업을 저비용으로 처리하려는 팀에게 매력적인 선택지가 된다. 특히 NeMo Switchyard와 조합하면 무거운 프론티어 모델과 경량 특화 모델을 작업 성격에 따라 나눠 쓰는 라우팅 아키텍처를 표준적으로 설계할 수 있어, 추론 비용 최적화 전략의 폭이 넓어진다.

**관련 링크:** [MarkTechPost](https://www.marktechpost.com/2026/08/11/nvidia-ai-releases-nemotron-3-5-lightning-and-nemo-switchyard/)

### 2. DeepSeek V4 Pro 0813 정식 출시, 오픈 웨이트 선두 탈환
**카테고리:** Open Source / LLM

**주요 내용:**
- DeepSeek가 V4 Pro의 0813 버전을 정식(GA)으로 공개했다. 총 1.6조 파라미터에 활성 파라미터 490억 규모로, 현재 다운로드 가능한 오픈 웨이트 모델 중 가장 크다.
- MIT 라이선스로 Hugging Face와 ModelScope에서 직접 내려받을 수 있고, 전 서비스에 걸쳐 1M 토큰 컨텍스트가 기본이 됐다.
- GDPval-AA 벤치마크에서 1554점으로 오픈 웨이트 모델 중 선두를 기록했으며, Artificial Analysis 지능 지수에서는 오픈 웨이트 추론 모델 2위에 올랐다. DeepSeek-V4-Pro-Max는 SWE-bench Verified에서 80.6%를 달성했다고 밝혔다.

**엔지니어 관점 포인트:**
MIT 라이선스와 공개 가중치라는 조건 덕분에 사내 인프라에 직접 배포해 데이터 유출 우려 없이 파인튜닝하려는 조직에게 실질적인 대안이 된다. SWE-bench Verified 80%대는 코딩 에이전트 파이프라인에 오픈 모델을 넣어도 실무 수준의 결과를 기대할 수 있다는 신호다. 다만 벤더가 제시한 벤치마크 수치는 아직 독립 검증이 진행 중인 만큼, 실제 도입 전에는 자체 워크로드 기준의 재현 테스트를 거치는 편이 안전하다.

**관련 링크:** [Artificial Analysis](https://artificialanalysis.ai/articles/deepseek-is-back-among-the-leading-open-weights-models-with-v4-pro-and-v4-flash)

### 3. Model Context Protocol, 2026-07-28 사양으로 최대 규모 개편
**카테고리:** Developer Tool / Protocol

**주요 내용:**
- 에이전트가 외부 시스템에 연결되는 방식을 정의하는 표준인 Model Context Protocol이 2026-07-28 사양을 통해 출시 이후 가장 큰 개편을 단행했다. 상태 비저장(stateless) 코어, 멀티 라운드트립 요청, 헤더 기반 라우팅, 캐시 가능한 목록 응답, 인가 강화, 공식 확장 프레임워크가 포함됐다.
- 기존에 sticky session과 공유 세션 저장소, 게이트웨이 심층 패킷 검사가 필요했던 원격 MCP 서버를 이제 일반 라운드로빈 로드밸런서 뒤에서 운영할 수 있다. 서버 렌더링 UI를 제공하는 MCP Apps와 장기 실행 작업을 위한 Tasks 확장도 함께 정의됐다.
- 인가 체계는 OAuth 및 OpenID Connect 배포와 더 밀접하게 정렬됐다. Tier 1 SDK는 월 5억 회에 가까운 다운로드를 기록하고 있으며, TypeScript와 Python SDK는 누적 10억 다운로드를 넘어섰다.

**엔지니어 관점 포인트:**
상태 비저장 코어로의 전환은 MCP 서버를 평범한 HTTP 인프라 위에서 수평 확장할 수 있게 만든다는 점에서 프로덕션 도입의 결정적 장벽을 낮춘다. 그동안 세션 고정과 전용 게이트웨이 때문에 미뤄졌던 원격 MCP 서버 운영이 일반적인 웹 서비스 배포 방식과 동일해지는 셈이다. OAuth/OIDC 정렬은 기업 SSO 환경과의 통합 부담을 줄여주며, MCP Apps와 Tasks 확장은 단순 툴 호출을 넘어 UI와 장기 작업까지 프로토콜 레벨에서 다루려는 방향을 보여준다.

**관련 링크:** [Model Context Protocol Blog](https://blog.modelcontextprotocol.io/posts/2026-07-28/)

### 4. 주요 AI 랩, 에이전트 프레임워크 경쟁 본격화
**카테고리:** Agentic AI / Developer Tool

**주요 내용:**
- Microsoft Agent Framework가 1.14.0을 내놓으며 Mistral 챗 클라이언트 지원, 워크플로 체크포인트 재개, 새로운 훅과 저장소 옵션을 추가했다. .NET용 1.18.0에서는 동시 툴 호출, Foundry 호스티드 세션과 사용자 신원 전달, Cosmos 대화 이력 조회 API가 들어갔다.
- Google ADK 2.0은 계층형 실행기에서 그래프 기반 실행 엔진으로 전환하면서 코디네이터 에이전트, 서브 에이전트 위임, fan-out/fan-in 패턴 등 정교한 멀티 에이전트 오케스트레이션을 지원한다.
- OpenAI, Anthropic, Google 등 주요 AI 랩이 저마다 에이전트 SDK를 출시하면서, AI 에이전트는 연구 데모 단계를 넘어 프로덕션 DevOps 자동화로 이동하고 있다.

**엔지니어 관점 포인트:**
그래프 기반 실행과 동시 툴 호출, 체크포인트 재개 같은 기능은 에이전트 프레임워크가 데모용 추상화에서 벗어나 실제 분산 워크플로 엔진의 요건을 갖춰가고 있음을 보여준다. 특히 체크포인트 재개와 장기 세션 지원은 장시간 실행되는 에이전트를 안정적으로 운영하는 데 필수적인 요소다. 다만 랩마다 SDK가 파편화되고 있어, 특정 프레임워크에 대한 종속을 줄이려면 MCP 같은 공통 프로토콜을 경계 계층으로 두고 오케스트레이션 로직을 분리하는 설계가 유리하다.

**관련 링크:** [Microsoft Agent Framework Blog](https://devblogs.microsoft.com/agent-framework/microsoft-agent-framework-at-build-2026-announce/)

### 5. EU AI Act 제50조 투명성 의무 발효
**카테고리:** Regulation / Developer Impact

**주요 내용:**
- EU AI Act 제50조의 투명성 의무가 2026년 8월 2일부터 발효됐다. AI와 상호작용하는 사용자에게 그 사실을 고지하고, AI가 생성하거나 조작한 콘텐츠를 식별 가능하게 표시하도록 요구하는 조항이다.
- 위반 시 제재 수준은 전 세계 매출의 최대 3%에 이른다.

**엔지니어 관점 포인트:**
제품에 생성형 AI 기능을 붙이는 팀이라면 이제 투명성 고지와 콘텐츠 워터마킹, 출처 메타데이터가 선택이 아니라 규제 준수 요건이 된다. 챗봇 UI의 AI 고지 문구, 이미지·영상 생성물의 표식 삽입, C2PA 같은 출처 표준 도입을 로드맵에 반영해야 한다. EU 시장을 대상으로 하는 서비스라면 매출 기반 과징금 규모를 고려할 때, 규제 대응을 엔지니어링 백로그의 후순위로 미루기 어려운 시점이 됐다.

**관련 링크:** [LLM Stats - AI News](https://llm-stats.com/ai-news)

## 오늘의 트렌드 한눈에 보기
이번 주 흐름을 관통하는 키워드는 오픈 웨이트 모델의 반격과 에이전트 인프라의 표준화다. Nemotron 3.5 Lightning과 DeepSeek V4 Pro는 각각 경량 로컬 실행과 대규모 오픈 웨이트라는 서로 다른 축에서, 폐쇄형 프론티어 모델에 의존하지 않고도 실무 수준의 성능을 확보할 수 있음을 보여준다. 동시에 모델들이 소프트웨어 패치처럼 빠르게 릴리스되면서, 개별 모델의 스펙보다 이들을 어떻게 라우팅하고 오케스트레이션하느냐가 더 중요한 설계 문제로 부상하고 있다. MCP의 상태 비저장 전환과 각 랩의 에이전트 프레임워크 경쟁은 그 오케스트레이션 계층을 프로덕션 인프라 위에 안정적으로 올리려는 움직임이며, EU AI Act 발효는 이렇게 빠르게 확산되는 AI 기능에 투명성과 거버넌스라는 제약 조건을 동시에 부과하고 있다. 결국 지금 엔지니어에게 필요한 것은 최신 모델을 쫓는 것보다, 교체 가능한 모델과 표준 프로토콜, 규제 대응을 함께 담을 수 있는 견고한 아키텍처를 설계하는 일이다.
