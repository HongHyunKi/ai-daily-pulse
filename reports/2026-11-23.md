## 오늘의 핵심 AI 뉴스 요약

### 1. [OpenAI Ruby SDK 1.0.0, Responses·Conversations 중심 API로 전환]
* **카테고리:** Developer Tool / LLM API
* **주요 내용:**
  - OpenAI의 공식 Ruby SDK가 1.0.0을 공개했습니다. Ruby 3.3 이상을 요구하며, Assistants·Threads API와 관련 타입을 제거하고 Responses·Conversations 사용을 기본 경로로 전환했습니다.
  - Sora 2 모델 상수와 `/v1/videos` Batch 경로 등 더 이상 지원되지 않는 항목이 제거됐고, Responses 압축 출력·Live Responses 위임·이미지 크기 타입 등도 1.0 API에 맞게 바뀌었습니다.
* **엔지니어 관점 포인트:**
  - Ruby 애플리케이션은 단순 버전 업이 아니라 API 마이그레이션 작업으로 다뤄야 합니다. 특히 Assistants·Threads 의존 코드, 영상 관련 호출, 타입 비교 로직을 먼저 검색해야 합니다.
  - Responses 압축 결과에 사용자·시스템·개발자 메시지와 압축 레코드가 함께 포함될 수 있으므로, 스트리밍·직렬화·감사 로그의 스키마 가정을 다시 검증해야 합니다.
* **관련 링크:** [openai-ruby v1.0.0 릴리스](https://github.com/openai/openai-ruby/releases/tag/v1.0.0)

### 2. [memhub 0.2.5, 코딩 에이전트 간 메모리 수집·보호 범위 강화]
* **카테고리:** Open Source / Agentic AI / Developer Tool
* **주요 내용:**
  - memhub가 0.2.5를 공개했습니다. 전체 턴을 `<private>`로 제외할 수 있고, `memhub_excluded_projects`로 특정 프로젝트의 수집·검색을 끌 수 있습니다.
  - DeepSeek Harness의 완료 턴 자동 수집, 예약 작업·백그라운드 리포트·하위 세션의 원본 대화 제외, 메모리 도구 응답의 건수·문자 수 제한이 추가됐습니다.
  - 릴리스 노트는 이미 설치된 호스트에 `memhub install-host`와 `memhub install-service` 재실행이 필요하다고 안내합니다.
* **엔지니어 관점 포인트:**
  - 여러 코딩 에이전트의 세션을 공유 메모리로 연결하는 흐름이 기능보다 데이터 경계와 보존 정책을 먼저 요구하고 있습니다.
  - 개인 정보·비밀·고객 코드가 메모리 인덱스로 유입되지 않도록 프로젝트 제외 목록과 비공개 턴 규칙을 기본값으로 설계하고, 업데이트 후 재설치 절차를 운영 문서에 반영해야 합니다.
* **관련 링크:** [memhub v0.2.5 릴리스](https://github.com/shibing624/memhub/releases/tag/v0.2.5)

### 3. [Job Agent 0.6.33, 브라우저 기반 에이전트 로그인 실패 처리 개선]
* **카테고리:** Developer Tool / Agentic AI
* **주요 내용:**
  - AgentMesh-JobAgent가 0.6.33을 공개했습니다. BOSS 로그인에서 전용 Chrome 창이 준비될 때까지 최대 30초 대기하도록 바뀌었습니다.
  - 다른 Chrome 인스턴스가 같은 Job Agent 프로필을 사용 중이면 종료 후 재시도 방법을 CLI에서 안내하고, Chrome이 시작 중 종료되면 종료 코드도 보고합니다.
* **엔지니어 관점 포인트:**
  - 브라우저를 조작하는 에이전트는 모델 품질보다 프로필 잠금·창 준비·프로세스 종료 같은 실행 환경 상태가 성공률을 좌우합니다.
  - 브라우저 자동화 작업은 전용 프로필과 단일 실행 보장, 명시적인 재시도 상한, 프로세스 종료 코드 수집을 기본 운영 조건으로 두는 편이 안전합니다.
  - 이번 릴리스는 특정 채용 사이트 로그인에 초점을 둔 소규모 변경이므로, 범용 브라우저 에이전트의 안정성 개선으로 확대 해석하지 않는 것이 좋습니다.
* **관련 링크:** [Job Agent v0.6.33 릴리스](https://github.com/jiyangnan/AgentMesh-JobAgent/releases/tag/v0.6.33)
