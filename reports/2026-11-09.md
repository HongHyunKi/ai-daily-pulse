## 오늘의 핵심 AI 뉴스 요약

### 1. OpenAI Agents SDK v0.24.0-alpha.7, 세션 저장·호스티드 도구·실행 정책 확장
* **카테고리:** Agentic AI / SDK / 실행 환경
* **주요 내용:**
  - Classic 런타임과 native execution을 함께 사용할 수 있게 하고, `CustomStorage`·`SQLiteSessionStore`로 애플리케이션이 대화 이력과 Python 도구 결과를 직접 보관할 수 있게 했다.
  - `FileSearch`, `CodeInterpreter`, `ImageGeneration` 같은 호스티드 도구, 컨텍스트 변환·압축 훅, 사용량 예산, MCP 리소스·프롬프트 탐색, 로컬 실행과 프로젝트 검색을 추가했다.
  - 새 Environment의 기본 쓰기 정책을 `write_policy="strict"`로 바꾸고, MCP 승인 모드 이름과 일부 콜백·elicitation API를 변경했다. 기본 추론 노력도 일부 모델에서 `low`에서 `medium`으로 바뀐다.
* **엔지니어 관점 포인트:**
  - 에이전트의 상태·도구·파일 권한을 애플리케이션이 명시적으로 소유하는 방향으로 API 경계가 넓어졌다. 운영 환경에서는 세션 복구와 불확실한 도구 효과의 재조정 정책을 먼저 설계해야 한다.
  - 프리릴리스이므로 바로 고정하기보다 `write_policy`, MCP 승인 모드, 콜백 시그니처, 추론 노력 기본값을 기존 코드와 비교하는 마이그레이션 테스트가 필요하다.
* **관련 링크:** [OpenAI Agents SDK v0.24.0-alpha.7 릴리스](https://github.com/openai/openai-agents-python/releases/tag/v0.24.0-alpha.7)

### 2. Vercel AI SDK 7.0.165, 텔레메트리의 민감 정보 노출 경로 차단
* **카테고리:** Developer Tool / SDK / 보안
* **주요 내용:**
  - `recordOutputs`가 꺼진 경우 음성 전사 단어 타이밍을 텔레메트리에 포함하지 않도록 수정했다.
  - 텍스트 생성 결과가 텔레메트리 통합과 tracing subscriber에 전달되기 전에 provider 요청 URL을 정리해 엔드포인트 자격 증명이 노출되지 않도록 했다.
  - 변경은 `ai@7.0.165` 패치 릴리스로 배포됐다.
* **엔지니어 관점 포인트:**
  - AI SDK의 추적 데이터는 모델 출력뿐 아니라 요청 URL과 음성 메타데이터까지 포함할 수 있으므로, 관측성 설정을 보안 경계로 다뤄야 한다.
  - Vercel AI SDK를 사용하면서 커스텀 provider·OpenTelemetry·tracing subscriber를 붙였다면 패치 버전으로 올린 뒤, URL 쿼리·헤더·전사 메타데이터가 외부 수집기로 전달되지 않는지 회귀 테스트하는 편이 안전하다.
* **관련 링크:** [Vercel AI SDK ai@7.0.165 릴리스](https://github.com/vercel/ai/releases/tag/ai%407.0.165)

### 3. CrewAI 1.15.37, 에이전트의 스프레드시트 읽기와 독립 프로젝트 스캐폴딩 추가
* **카테고리:** 오픈소스 / Agentic AI / 개발자 도구
* **주요 내용:**
  - `crewai-files`에 에이전트가 스프레드시트를 읽을 수 있는 기능을 추가했다.
  - 독립형 에이전트 프로젝트를 스캐폴딩하고 불러오는 흐름을 추가했다.
  - 릴리스는 2026년 11월 7일에 공개됐다.
* **엔지니어 관점 포인트:**
  - 표 형식의 운영 데이터를 에이전트 워크플로우에 연결하는 진입 장벽이 낮아졌지만, 파일 권한·열 단위 개인정보·대용량 처리 한계를 별도 검증해야 한다.
  - 독립 프로젝트 생성 기능을 CI나 팀 템플릿에 넣기 전에는 생성물의 의존성 고정, 환경 변수 처리, 재실행 시 덮어쓰기 동작을 확인해야 한다.
* **관련 링크:** [CrewAI 1.15.37 릴리스](https://github.com/crewAIInc/crewAI/releases/tag/1.15.37)
