### 1. Moonshot AI, 사상 최대 규모의 오픈 웨이트 모델 Kimi K3 공개
**카테고리:** Open Source / LLM

**주요 내용:**
- Moonshot AI가 7월 26일(현지 시각) Hugging Face에 Kimi K3의 웨이트를 공개하며, 총 파라미터 2.8조 규모로 역대 최대 오픈 웨이트 모델 기록을 세웠다.
- Mixture-of-Experts(MoE) 구조로 전체 2.8조 파라미터 중 활성 파라미터는 약 1,040억 개이며, 컨텍스트 윈도우는 약 100만(1,048,576) 토큰을 지원한다.
- 공식 리포지토리에는 96개의 웨이트 샤드와 라이선스, 설정 파일, 배포 가이드가 포함됐다. 다만 MXFP4 4비트 정밀도로도 웨이트 로딩에만 약 1.4TB의 고속 메모리가 필요해, 컨텍스트를 올리기 전부터 인프라 부담이 크다.

**엔지니어 관점 포인트:**
오픈 웨이트 진영이 프론티어 클로즈드 모델과의 성능 격차를 빠르게 좁히고 있다는 점이 핵심이다. 자체 호스팅이 가능해지면 API를 통한 데이터 유출 우려나 지정학적 리스크를 구조적으로 줄일 수 있어, 규제 산업이나 온프레미스 요구가 강한 조직에는 실질적인 선택지가 된다. 다만 1.4TB급 메모리 요건은 사실상 대규모 GPU 클러스터를 전제로 하므로, 대부분의 팀에게 현실적인 경로는 직접 서빙보다는 양자화 버전이나 서드파티 호스팅 활용이 될 가능성이 높다. 모델 자체의 무료 공개와 실제 운영 비용 사이의 간극을 어떻게 메우느냐가 도입의 관건이다.

**관련 링크:** [Moonshot AI releases Kimi K3 open-weight model (Quartz)](https://qz.com/moonshot-ai-kimi-k3-open-weights-download-072726)

### 2. MCP 2026-07-28 스펙 확정, 스테이트리스 코어로 전환
**카테고리:** Developer Tool / Protocol

**주요 내용:**
- Model Context Protocol의 2026-07-28 스펙이 확정 공개됐다. 기존의 양방향 스테이트풀 프로토콜에서 요청/응답 기반의 스테이트리스 모델로 전환한 것이 가장 큰 변화다.
- initialize 핸드셰이크와 Mcp-Session-Id 헤더를 제거해, 어떤 요청이든 임의의 서버 인스턴스로 라우팅될 수 있게 됐다. 이로써 서버리스와 엣지 인프라 위에서의 배포가 가능해진다.
- 이번 리비전은 스테이트리스 코어, 첫 공식 Extension인 MCP Apps, 재설계된 Tasks 익스텐션, 인증 강화 패키지, 그리고 처음 도입된 공식 deprecation 정책을 함께 담았다. Tasks는 tools/call이 태스크 핸들을 반환하고 클라이언트가 tasks/get·update·cancel로 진행을 제어하는 방식이다.

**엔지니어 관점 포인트:**
스테이트리스 전환은 MCP 서버의 배포·확장 방식을 근본적으로 바꾼다. 세션 상태를 서버가 들고 있지 않아도 되므로 오토스케일링과 무중단 배포가 쉬워지고, 상시 구동 서버 대신 서버리스 함수로 비용을 낮출 여지가 생긴다. 반면 기존 스테이트풀 가정에 의존하던 서버는 마이그레이션이 불가피하며, 장기 실행 작업은 Tasks 익스텐션 기반의 폴링 모델로 재설계해야 한다. 새 프로토콜에 대응하는 SDK와 클라이언트 생태계가 얼마나 빠르게 안정화되는지가 실무 적용 시점을 좌우할 것이다.

**관련 링크:** [The 2026-07-28 MCP Specification (Model Context Protocol Blog)](https://blog.modelcontextprotocol.io/posts/2026-07-28/)

### 3. Anthropic, 프론티어 모델 Claude Fable 5 공개
**카테고리:** LLM

**주요 내용:**
- Anthropic이 Mythos 클래스 프론티어 모델인 Claude Fable 5를 공개했다. 현재 공개적으로 이용 가능한 가장 높은 성능의 LLM으로 소개됐으며, 여러 벤치마크에서 큰 폭의 향상을 보였다.
- 성능 향상의 대가로 비용은 Opus 계열 대비 약 2배 수준으로 책정됐다.
- Anthropic은 같은 흐름에서 Claude Sonnet 5도 함께 내놓으며 라인업을 재정비했다.

**엔지니어 관점 포인트:**
프론티어 성능이 필요한 복잡한 추론·에이전트 작업과 비용 효율이 중요한 대량 처리 작업 사이에서 모델을 계층적으로 나눠 쓰는 전략이 점점 더 중요해진다. Fable 5의 2배 비용은 모든 요청에 무차별적으로 최상위 모델을 쓰는 방식이 비경제적임을 시사하며, 라우팅 계층을 두고 난이도에 따라 Sonnet과 Fable을 선택적으로 호출하는 아키텍처가 합리적인 선택이 된다. 벤치마크 상의 우위가 실제 프로덕션 워크로드에서의 정확도·안정성으로 이어지는지는 팀별 자체 평가로 검증할 필요가 있다.

### 4. Anthropic, Claude Code 대규모 업데이트 및 Claude in Chrome 정식 출시
**카테고리:** Developer Tool / Agentic AI

**주요 내용:**
- Anthropic이 Claude Code에 대한 대규모 업데이트를 배포했다. 기본 모델이 Sonnet 5로 변경됐고, 백그라운드 서브에이전트가 기본 활성화됐다.
- Claude in Chrome이 정식(GA) 출시되어 브라우저 기반 에이전트 작업을 폭넓게 쓸 수 있게 됐다.
- 이 외에 Claude Desktop의 Linux 베타, /radio(Claude FM) 커맨드 등이 함께 추가됐다.

**엔지니어 관점 포인트:**
백그라운드 서브에이전트의 기본 활성화는 단일 에이전트가 순차적으로 작업하던 방식에서 병렬 위임 기반 워크플로우로의 전환을 의미한다. 큰 작업을 하위 태스크로 쪼개 동시에 처리하면 처리량이 늘지만, 컨텍스트 분리와 결과 병합, 토큰 소비 관리 같은 오케스트레이션 설계가 새로운 고려사항이 된다. 브라우저 에이전트의 정식화는 웹 기반 반복 작업의 자동화 범위를 넓히는 동시에, 링크 신뢰성과 권한 범위 같은 보안 설계를 실무 표준으로 끌어올리는 계기가 될 것이다.

### 5. OpenAI, GPT-5.6 모델 패밀리 정식 배포
**카테고리:** LLM

**주요 내용:**
- OpenAI가 신규 플래그십 GPT-5.6 패밀리를 Luna, Terra, Sol 세 가지 크기로 출시했다. 7월 9일부터 ChatGPT, Codex, API 전반에 걸쳐 배포됐다.
- 세 모델 모두 100만 토큰 컨텍스트 윈도우와 2026년 2월 지식 컷오프를 공유하며, 가격은 입력 100만 토큰당 1달러에서 5달러 사이로 책정됐다.

**엔지니어 관점 포인트:**
동일 세대 내에서 크기와 가격을 세분화해 제공하는 방식은 이제 주요 랩들의 공통 전략으로 자리잡았다. 100만 토큰 컨텍스트가 표준에 가까워지면서, 대용량 문서나 코드베이스 전체를 한 번에 넣는 접근이 현실화되지만 컨텍스트가 길어질수록 비용과 지연이 함께 늘어난다는 점은 여전하다. 결국 RAG를 통한 선별적 컨텍스트 주입과 롱 컨텍스트 직접 투입 사이의 트레이드오프를 워크로드별로 저울질하는 판단이 중요해진다. 크기별 라인업은 이 최적화의 선택지를 넓혀준다.

## 오늘의 트렌드 한눈에 보기
이번 주 흐름을 관통하는 키워드는 두 가지다. 첫째는 오픈 웨이트의 급격한 추격이다. Kimi K3가 2.8조 파라미터로 역대 최대 오픈 모델 기록을 세우면서, 클로즈드 프론티어와 오픈 진영의 성능 격차가 빠르게 좁혀지고 있음이 분명해졌다. 다만 공개된 웨이트를 실제로 굴리는 데 드는 인프라 비용은 여전히 높아, 모델의 무료화가 곧바로 도입 비용의 무료화로 이어지지는 않는다. 둘째는 인프라와 프로토콜 계층의 성숙이다. MCP의 스테이트리스 전환, Claude Code의 백그라운드 서브에이전트 기본화, 그리고 주요 랩들이 공통적으로 채택한 크기·가격 세분화 라인업은 모두 에이전트를 안정적으로 확장·운영하기 위한 토대 정비에 해당한다. 모델 성능 경쟁이 거의 매일 새 모델이 나오는 수준으로 가속화되는 가운데, 개발자에게 실질적인 차이를 만드는 지점은 어떤 모델을 쓰느냐보다 이들을 어떻게 라우팅하고 오케스트레이션하며 비용을 통제하느냐로 이동하고 있다.
