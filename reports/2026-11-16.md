## 오늘의 핵심 AI 뉴스 요약

### 1. GitHub Copilot, 일부 모델 지원 종료가 오늘 적용 — 기본 모델 정책 점검 필요
* **카테고리:** Developer Tool / LLM / Model Lifecycle
* **주요 내용:**
  - GitHub가 사전 공지한 Claude Opus 4.8, Claude Opus 5, GPT-5.6 Terra의 Copilot 지원 종료가 11월 16일 적용된다.
  - GitHub는 대체 모델로 각각 Claude Opus 5.5, GPT-6.1 Sol 또는 GPT-6 Luna를 제시했으며, Business·Enterprise에서는 관리자가 기본 모델 정책을 꺼두지 않았다면 대체 모델이 자동 활성화될 수 있다고 설명했다.
  - Claude Opus 4.8은 연간 플랜의 개인 구독자에게는 Opus 선택지를 유지하기 위해 예외가 적용된다. 모델 ID를 직접 고정한 API·자동화·평가 파이프라인은 별도 점검이 필요하다.
* **엔지니어 관점 포인트:**
  - 모델 교체는 단순한 이름 변경이 아니라 출력 형식, 도구 호출, 비용, 지연시간, 안전 정책이 바뀌는 운영 이벤트다. 오늘부터 CI와 주요 에이전트 작업에서 실제 선택 모델과 실패율을 기록해야 한다.
  - Copilot에 의존하는 저장소는 모델 ID를 코드·프롬프트·평가 기준에 하드코딩하지 말고, 지원 모델 목록과 대체 모델의 회귀 테스트를 함께 관리하는 편이 안전하다.
* **관련 링크:** [GitHub Changelog: Upcoming deprecation of selected GitHub Copilot models](https://github.blog/changelog/2026-10-15-upcoming-deprecation-of-selected-github-copilot-models-in-mid-November/)

### 2. llama.cpp b12407 공개 — LFM3용 Metal 텐서 융합 우회 수정 포함
* **카테고리:** Open Source / Inference / Developer Tool
* **주요 내용:**
  - ggml-org가 11월 15일 `b12407` 프리릴리스를 공개했다.
  - 이번 변경은 LFM3에서 Metal의 fusion 경로를 사용할 때 발생하는 문제를 우회하도록 잔차 덧셈에서 정규화된 텐서의 순서를 조정한 수정이다.
  - GitHub Container Registry에는 CUDA·ROCm·Vulkan·OpenVINO 등 여러 실행 환경용 이미지가 함께 게시돼 있어, 특정 하드웨어 백엔드만 사용하는 팀도 변경을 선택적으로 검증할 수 있다.
* **엔지니어 관점 포인트:**
  - 로컬 LLM 운영에서는 모델 성능보다 백엔드별 커널·그래프 최적화가 실제 지연시간과 안정성을 좌우한다. LFM3를 Apple Silicon에서 구동한다면 최신 프리릴리스의 정확도와 토큰 생성 속도를 기존 이미지와 비교할 가치가 있다.
  - 프리릴리스이므로 운영 이미지에 즉시 고정하기보다 모델별 프롬프트 회귀, 스트리밍 안정성, Metal 메모리 사용량을 확인한 뒤 버전을 고정해야 한다.
* **관련 링크:** [GitHub: llama.cpp b12407 release](https://github.com/ggml-org/llama.cpp/releases/tag/b12407)

### 3. OpenAI Codex CLI 0.171.0-alpha.6 공개 — 에이전트 터미널의 빠른 프리릴리스 주기 지속
* **카테고리:** Agentic AI / Developer Tool
* **주요 내용:**
  - OpenAI가 11월 15일 18:58 UTC에 Codex CLI `0.171.0-alpha.6` 프리릴리스를 공개했다.
  - 해당 버전은 정식 안정 릴리스가 아닌 사전 릴리스이며, GitHub 릴리스 페이지에는 196개 플랫폼별 자산이 제공된다.
  - 이번 릴리스 페이지에는 상세 변경 목록이 노출되지 않았으므로, 현재 확인 가능한 사실은 사전 릴리스 공개와 플랫폼별 배포 자산 제공이다. 기능 변경은 설치 후 별도 검증이 필요하다.
* **엔지니어 관점 포인트:**
  - 에이전트 CLI는 일반 라이브러리보다 변경 속도가 빠르므로 팀 공용 개발 환경에서는 `latest` 설치를 피하고 안정 버전·프리릴리스 채널을 분리해야 한다.
  - 프리릴리스를 시험할 때는 권한 승인, 셸 실행, MCP 연결, 작업 재개처럼 데이터와 외부 시스템에 영향을 주는 경로를 별도 스모크 테스트하고, 문제가 생기면 즉시 안정 버전으로 되돌릴 수 있어야 한다.
* **관련 링크:** [GitHub: OpenAI Codex CLI 0.171.0-alpha.6](https://github.com/openai/codex/releases/tag/rust-v0.171.0-alpha.6)

### 4. GitHub Copilot CLI 1.0.112 공개 — 압축 실패 메시지와 붙여넣기 복구 동작 개선
* **카테고리:** Developer Tool / Agentic AI
* **주요 내용:**
  - GitHub가 11월 13일 23:59 UTC에 Copilot CLI `1.0.112`를 공개했다.
  - `/compact`가 실패할 때 내부 호스트 재전달 접두사 대신 모델 제공자의 오류 메시지를 표시해 원인 파악을 쉽게 했다.
  - 관리 계정 정책을 불러오는 동안 아직 전송되지 않은 프롬프트를 입력한 경우, 붙여넣은 텍스트를 보존해 다시 Enter를 눌러도 `[Paste #N - M lines]` 같은 자리표시자가 전송되지 않도록 수정했다.
* **엔지니어 관점 포인트:**
  - 에이전트 CLI의 생산성은 모델 성능뿐 아니라 실패 시 복구 가능성과 사용자가 실제로 무엇을 전송했는지 예측할 수 있는 인터페이스에 달려 있다.
  - 조직 표준 이미지에 업데이트를 반영할 때는 압축·재개·관리 정책 로딩·대량 붙여넣기 같은 긴 세션 경로를 확인하고, 운영 로그에 프롬프트 원문이나 비밀이 남지 않는지도 함께 점검해야 한다.
* **관련 링크:** [GitHub: Copilot CLI 1.0.112 release](https://github.com/github/copilot-cli/releases/tag/v1.0.112)
