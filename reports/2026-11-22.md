### 1. [OpenHands 1.43.0, 자동화 설정과 실험 기능 강화]
* **카테고리:** Open Source / Agentic AI
* **주요 내용:**
  - OpenHands가 1.43.0을 공개했습니다. 설정 마법사에서 자동화를 생성할 때 바로 활성화할 수 있게 됐고, 실험적 기능 플래그를 관리하는 Features 페이지가 추가됐습니다.
  - 대화형 의사결정 카드, 에이전트 메시지 편집 표시, 자동화 실행 행의 대화 표시, 대화 목록 가상화와 관련된 기능·성능 개선이 포함됐습니다.
* **엔지니어 관점 포인트:**
  - 에이전트 기능이 일회성 작업을 넘어 반복 자동화로 이동하고 있습니다. 운영 환경에 적용할 때는 자동 활성화된 작업의 권한, 트리거, 실패 재시도 정책을 먼저 점검해야 합니다.
  - 실험 기능이 별도 플래그로 노출되므로 팀 표준 환경에서는 기능 플래그와 버전을 고정하는 편이 안전합니다.
* **관련 링크:** [OpenHands v1.43.0 릴리스](https://github.com/OpenHands/OpenHands/releases/tag/v1.43.0)

### 2. [Claude Code 2.1.330, 조직 관리와 셀프 호스팅 실행 기능 추가]
* **카테고리:** Developer Tool / Agentic AI
* **주요 내용:**
  - Claude Code가 Anthropic Enterprise Admin Console에서 관리되는 조직으로 로그인할 수 있게 됐습니다. 조직 설정과 클라우드 공급자 또는 게이트웨이 구성을 적용합니다.
  - 셀프 호스팅 러너의 시작 디렉터리를 지정하는 `--start-dir`와 `SELF_HOSTED_RUNNER_START_DIR`가 추가됐고, 플러그인 설치 결과의 성공·실패 상태와 러너 지연시간 메트릭이 보강됐습니다.
  - 긴 대화 압축 직후 수 분간 멈출 수 있던 문제도 수정됐습니다.
* **엔지니어 관점 포인트:**
  - 코딩 에이전트가 개인 CLI에서 조직 정책과 자체 실행 인프라를 연결하는 배포 단위로 확장되고 있습니다.
  - 러너의 작업 디렉터리와 플러그인 소스가 분리되는 만큼, CI에서 권한 범위와 플러그인 저장소 허용 목록을 명시적으로 관리해야 합니다.
* **관련 링크:** [Claude Code v2.1.330 릴리스](https://github.com/anthropics/claude-code/releases/tag/v2.1.330)

  - 실시간 음성·멀티모달 연결에서 대기 상태를 활용할 수 있어 세션 재개와 연결 수명 관리 설계가 중요해집니다.
  - SDK 업데이트 전후로 WebRTC 연결 상태, 재접속, 인증 만료, 비용 집계에 대한 통합 테스트를 고정해 두는 것이 좋습니다.
  - provenance가 제공되는 패키지를 사용하고 배포 파이프라인에서 버전·해시 검증을 켜면 공급망 확인 절차를 단순화할 수 있습니다.
* **관련 링크:** [openai-python v3.57.0 릴리스](https://github.com/openai/openai-python/releases/tag/v3.57.0)

### 4. [ACP Registry, Cline·Factory Droid·Nova·pi ACP 버전 갱신]
* **카테고리:** Open Source / Agentic AI / Developer Tool
* **주요 내용:**
  - Agent Client Protocol(ACP) Registry가 11월 21일 릴리스에서 등록 에이전트 4개의 배포 버전을 갱신했습니다.
  - Cline은 3.0.74에서 3.0.75로, Factory Droid는 1.16.0에서 1.17.0으로, Nova는 1.1.67에서 1.1.68로, pi ACP는 0.0.34에서 0.0.35로 올라갔습니다.
  - Registry는 npm·PyPI·GitHub 릴리스를 확인해 에이전트 버전을 자동 갱신하며, 각 항목의 배포 정보와 인증 호환성을 관리합니다.
* **엔지니어 관점 포인트:**
  - 에이전트 클라이언트와 실행기를 연결하는 공통 프로토콜 계층이 단순 문서가 아니라 배포 카탈로그로 운영되고 있습니다.
  - 여러 코딩 에이전트를 IDE나 오케스트레이터에 붙일 때 개별 설치 스크립트보다 Registry의 버전·배포 메타데이터를 기준으로 검증하면 업데이트 추적이 쉬워집니다.
  - 자동 갱신은 편리하지만, 조직 환경에서는 안정 버전과 preview 채널을 분리하고 허용 버전을 잠그는 정책이 필요합니다.
* **관련 링크:** [ACP Registry v2026.11.21-87e1f8b 릴리스](https://github.com/agentclientprotocol/registry/releases/tag/v2026.11.21-87e1f8b) · [업데이트 커밋 상세](https://github.com/agentclientprotocol/registry/commit/87e1f8b)
