### 1. OpenAI, GPT-6.1 Sol 공개와 전 사용자 쿼터 리셋

**카테고리:** LLM

**주요 내용:**
- OpenAI가 9월 29일 GPT-6.1 Sol을 출시했다. 상위 Astra 등급에 근접하면서도 가격은 입력 100만 토큰당 2달러, 출력 100만 토큰당 10달러로 책정한 저가형 라인이다.
- 출시 초기 응답 품질과 속도 문제가 이어지자, OpenAI는 10월 2일 모든 유료 ChatGPT 계정의 사용량 한도를 일괄 초기화하며 사실상의 사과 조치를 내놨다.

**엔지니어 관점 포인트:**
Sol의 토큰 단가는 Anthropic의 Sonnet 5.5와 정확히 동일한 지점에 놓였다. 프런티어 성능을 추구하던 경쟁이 이제 비슷한 성능대에서 단가를 깎는 싸움으로 옮겨가고 있다는 신호다. 대량 추론을 돌리는 서비스라면 더 이상 한 모델에 고정될 이유가 줄어든다. 동일 가격대에서 품질과 지연 시간만 비교해 라우팅하는 구조를 미리 설계해두면, 출시 직후의 품질 불안정 구간에서 특정 모델에 묶이는 위험을 피할 수 있다.

**관련 링크:** [AI News Today, October 2](https://aiweekly.co/ai-news-today)

### 2. Anthropic Claude Sonnet 5.5, 같은 가격에 속도와 비용 효율 개선

**카테고리:** LLM

**주요 내용:**
- Anthropic이 9월 28일 Claude Sonnet 5.5를 출시했다. 이전 Sonnet 5 대비 30% 이상 빠르고, 대부분의 작업에서 최대 30% 저렴하게 동작한다고 밝혔다.
- 가격은 Sonnet 5와 동일하게 입력 100만 토큰당 2달러, 출력 100만 토큰당 10달러, 캐시 읽기 100만 토큰당 0.2달러를 유지했다. AWS, Google Cloud, Microsoft Azure를 포함한 전 플랫폼에서 이용 가능하다.
- 버그 수정, 문서·슬라이드·스프레드시트 작성 같은 범위가 명확한 실무 작업에 강점이 있으며, 원본 문서의 데이터를 다시 대조해 Sonnet 5가 놓치던 오류를 잡아낸다.

**엔지니어 관점 포인트:**
가격을 그대로 두고 속도와 정확도만 끌어올린 업데이트라, 기존 Sonnet 5 기반 파이프라인은 모델 문자열 교체만으로 비용 절감 효과를 얻을 수 있다. 특히 원본 대조로 오류를 줄였다는 점은 문서 요약이나 데이터 추출처럼 환각이 치명적인 워크플로우에서 후처리 검증 부담을 덜어준다. 캐시 읽기 단가가 입력 대비 10분의 1 수준이라, 긴 시스템 프롬프트나 반복 문맥을 쓰는 에이전트는 프롬프트 캐싱 설계로 체감 비용을 크게 낮출 여지가 있다.

**관련 링크:** [TechCrunch - Anthropic releases Sonnet 5.5](https://techcrunch.com/2026/09/28/anthropic-releases-sonnet-5-5-which-it-calls-a-significantly-cheaper-faster-work-partner/)

### 3. Cloudflare, 오픈 결정 모델 Clef와 Clef-flash 공개

**카테고리:** Open Source / Developer Tool

**주요 내용:**
- Cloudflare가 분류, 라우팅, 에이전트 의사결정을 위한 오픈 결정 모델 Clef와 Clef-flash를 공개했다. 허용된 선택지를 직접 점수화하는 방식으로 동작한다.
- Clef-flash는 중앙값 지연 시간이 약 39ms로 보고됐고, 두 모델 모두 Apache-2.0 라이선스로 공개되어 Workers AI에서 호스팅된다.

**엔지니어 관점 포인트:**
에이전트 파이프라인에서 분기·라우팅 판단에까지 범용 LLM을 호출하는 것은 비용과 지연 측면에서 과한 선택인 경우가 많다. Clef처럼 선택지를 직접 점수화하는 전용 결정 모델은 이 판단 레이어를 수십 밀리초 단위로 떼어낼 수 있게 한다. 40ms 수준의 지연과 Apache-2.0 라이선스 조합은 실시간 요청 라우팅이나 입력 분류 게이트웨이에 바로 투입할 수 있는 조건이다. 무거운 생성 모델은 실제 생성이 필요한 경로에만 남기고, 결정 로직은 경량 모델로 분리하는 아키텍처가 현실적인 선택지로 자리잡고 있다.

**관련 링크:** [New Models Today - pricepertoken](https://pricepertoken.com/news/model-releases)

### 4. Tavus Griffin-Lite, 실시간 양방향 영상 상호작용 모델 등장

**카테고리:** Agentic AI / Multimodal

**주요 내용:**
- Tavus가 10월 1일 Griffin-Lite를 공개하며 이를 최초의 Human Interaction Model이라 명명했다. 인식, 응답 시점 판단, 음성·영상 동시 생성을 하나로 묶은 풀 듀플렉스 video-to-video 시스템이다.
- 1분 길이 영상 통화 실험에서 참가자 54명 중 26명(48%)이 Griffin을 실제 사람으로 인식했다.

**엔지니어 관점 포인트:**
텍스트 챗봇에서 음성 에이전트로, 다시 양방향 영상 에이전트로 상호작용 모달리티가 확장되는 흐름의 연장선이다. 핵심은 "언제 응답할지"를 모델이 스스로 판단하는 풀 듀플렉스 구조로, 기존의 턴 기반 요청-응답 패턴과는 설계가 근본적으로 다르다. 끼어들기 처리, 침묵 구간 판단, 음성과 영상의 동기화 같은 실시간 스트리밍 문제가 전면에 등장한다. 동시에 48%가 사람으로 오인했다는 결과는 영상 통화에 대화 상대가 사람임을 알리는 고지 장치가 제품 요건이 되어가고 있음을 시사한다.

**관련 링크:** [Daily AI Recap October 2, 2026](https://x.com/NeoAIForecast/article/2105966638927397167)

## 오늘의 트렌드 한눈에 보기

오늘 수집된 소식들을 관통하는 축은 두 가지다. 하나는 프런티어 성능 경쟁에서 가격·속도 경쟁으로의 이동이다. GPT-6.1 Sol과 Claude Sonnet 5.5가 입력 2달러, 출력 10달러라는 동일한 지점에서 맞붙은 것은 우연이 아니라, 성능 격차가 좁혀진 구간에서 단가와 지연 시간이 실질적인 선택 기준이 되고 있음을 보여준다. 개발자 입장에서는 특정 모델에 고정되기보다 동일 가격대에서 품질과 비용을 비교해 라우팅하는 전략의 가치가 커진다. 다른 하나는 작업의 분해다. Cloudflare의 Clef는 결정 로직을 경량 전용 모델로 떼어내고, Tavus의 Griffin-Lite는 영상 상호작용이라는 새로운 모달리티를 전담한다. 하나의 거대 모델이 모든 것을 처리하는 구조에서, 역할별로 특화된 모델을 조합하는 파이프라인 설계로 무게 중심이 옮겨가는 중이다.
